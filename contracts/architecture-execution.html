Rules and validation

  • Commit task-specific files only. Preserve unrelated changes in every sibling repository.
  • Use live sibling sources through local-build, not stale revision pins.
  • Keep v1 payloads, stream names, privilege boundaries and same-user trust assumptions explicit. No effect replay after uncertain execution.
  • Run Rust tests, Clippy, formatting, relevant native QML tests, fixture freshness and Nix gates per stage. Record unavailable architecture/environment gates as blockers, not passes.
  • Changes to APIs or models must be reflected in production-generated fixtures. Never fabricate replacement wire envelopes inside consumer tests.

P2.4a evidence and limitations

  • The shared reader retains at most the configured limit plus one possible CR byte, in addition to fixed reader buffering. Oversized records are drained to LF/EOF, reported once and never parsed as truncated calls or executable suffixes. Tests cover byte rather than character bounds, split UTF-8/CRLF, exact limits, EOF, cancellation-safe partial/discard state, and the original fatal invalid-UTF-8 diagnostic.
  • The app regression runs two actual client binaries against an actual daemon on a private session bus, with only a temporary fake launcher/compositor. Before the fix an oversized launch was accepted; after it the launcher is untouched, the other bridge progresses during an unterminated oversized frame, and both remain usable. Identical frontend route identifiers do not grant cross-owner cancellation, operation status or event access.
  • Clipboard's separate binary regression submits a valid escaped 256 KiB text payload exceeding the small RPC limit. It reaches the intentionally unavailable transport rather than a real clipboard service. This protects existing bulk publication/edit behavior without claiming large output bounds.
  • Final checks use live sibling sources through local-build. Framework and clipboard Nix gates, the complete QML/freshness/lint gate, all five daemon Rust suites, Clippy, formatting and boundary checks passed. Native evidence: /tmp/p24a-before.log, /tmp/p24a-final-*-tests.log; final gates: /tmp/p24a-final-{nix,framework-nix,clip-nix,native}.exit, all zero.
  • These are input-record bounds, not a process-wide memory budget, server admission policy, request deadline, direct-D-Bus or result-size guarantee. P2.4b/P2.4c and P3–P7 remain incomplete.
