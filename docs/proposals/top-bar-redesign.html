A

The refined strip

Keep the familiar silhouette. Replace visual noise with a consistent, understated hierarchy.

Recommended starting point
2026-10-0710:32
One surface. Three clear roles. / 50px study height

Sage + charcoal
Quiet active-workspace tileOne passive media pillNumeric clock, subdued date
The design move

Reduce the outer border contrast. Use a rounded-square workspace highlight instead of competing rings. A fine divider separates navigation from media; the rest of the surface stays empty.

Why it works

The least disruptive improvement. Existing positions remain familiar. A 32px target rhythm and a 16–18px status-glyph family make the right side feel composed rather than appended.

Watch out for

The long empty strip is still present on ultrawide monitors. Keep it deliberately low-contrast; don’t fill it with track titles or extra telemetry just to use the space.

B

The floating groups

Remove the bridge. Let task controls and system status sit in two purposeful islands.

Strongest ultrawide alternative

Ice blue + slate
Task islandTransparent, non-interactive middleSystem island
The design move

Keep workspaces and media together in a left island. Give status its own right island. Match their height, radius and baseline; the media sub-group retains a quieter inner tone.

Why it works

Best answer to the very wide screenshot. The empty middle becomes actual negative space instead of a giant empty container. System controls stay predictably anchored to the edge.

Watch out for

More compositor work: only the islands should accept pointer input. Keep the existing reserved top area; do not imply that apps can occupy it. At very narrow widths, merge into the shared strip and overflow behavior.

C

The edge rail

Less decoration, more desktop infrastructure. A flat band that quietly belongs to the screen.

For a utilitarian desktop
2026-10-0710:32
Make the bar recede, not float. / 46px study height

Limestone + graphite
Short workspace underlineNo outer radius or shadowRestrained media accent
The design move

Attach the surface to the top edge. Remove outer rounding and shadow. Mark the current workspace with a short underline; keep the grouped media background so transport still reads as a unit.

Why it works

Calm, precise, keyboard-first in character. It fits a tiling workflow and visually aligns with application edges. The strongest value is consistency, not ornament.

Watch out for

Less expressive than the current Material direction. Keep the thin active marker legible at fractional scaling. This sketch changes visual height only; changing the exclusive zone would be a separate decision.

My recommendation

Start with A.
Keep B as the bold option.

A improves what you already have without changing where anything lives: quieter boundaries, more deliberate workspace states, consistent status spacing, and a single clearly grouped media control.

If the uninterrupted strip itself is what bothers you on a 3440px display, choose B. It solves that specific problem most directly. C is worth choosing only if you want the whole shell to become flatter and more utilitarian.

Palettes are illustrative. Carry the selected geometry into Shelllist’s shared theme roles rather than hard-coding a second theme.

Change the presentation. Keep the contract.

Shared behavior across all three

  • Keep the order: Workspaces → Media → Network → Bluetooth → Battery → Notifications → Tray → Clock/date.
  • Artwork opens Media. Play and seek remain separate capability-guarded actions. The media pill itself never becomes a button. Illustrative artwork here is not player metadata.
  • Compact mode keeps the artwork opener and removes transport. Keep workspace scrolling and active-item reveal. At extreme widths, retain explicit bar overflow; do not shrink targets indefinitely.
  • Tray applications stay in the chooser behind the ellipsis. Keep the numeric date/time and existing clock action. No new permanent telemetry, tooltips or shortcut legends.
  • Urgency stays static and distinct from selection. Offline uses a disconnected-network symbol, not a radio-off symbol. Accessible names must retain actual status details.

A practical first pass

  • bar/BarContent.qml — outer geometry, cluster spacing and date/time emphasis. Retain the current 51px exclusive zone initially; visual study heights are not deployment values.
  • bar/WorkspaceButton.qml — active tile or underline, distinct occupancy and urgency. Production app icons remain real icons; the drawings here are stand-ins.
  • bar/MediaChip.qml — refine the existing passive group, not its routing or click boundaries.
  • bar/BarAction.qml and shared theme roles — align status glyphs and local hover/press feedback. Do not add panel browsing markers or new field Tab stops to the bar.
  • Before shipping, add/update real Qt coverage for density, action targets, disabled transport and urgency; check 3440 / 1200 / 700 / 300px, fractional scaling, light theme, and live compositor input masks.
Scope and design constraints

This is a visual proposal, not a QML implementation. Only the supplied bar screenshot is being redesigned; the wallpaper is illustrative. Existing panels, shortcuts, save/discard transactions, backend acknowledgement and safety guards remain unchanged. The current chooser interaction contract takes precedence over older proposals. A selected direction would still need full light-theme, larger-text, screen-reader and live compositor validation. The HTML preview uses ordinary web buttons for review controls, not as a model for native panel navigation.
