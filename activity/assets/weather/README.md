# Weather artwork

The SVG artwork in this directory is a vendored subset of
[Meteocons](https://github.com/basmilius/meteocons), created by Bas Milius and
licensed under the MIT license. The copied license is in
`LICENSE.meteocons`.

The static `fill` variants are bundled locally so weather rendering does not
require a CDN or disclose location-view activity to a third party.
